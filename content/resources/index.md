# Resources

## Official

- [Core Rules PDF](https://www.warhammer-community.com/en-gb/downloads/warhammer-40000/): free core rules
- [The 40k App](https://app.warhammer40000.com/subscriptions): list building and rules reference
- [Warhammer Community](https://www.warhammer-community.com): news and articles. You find the important updates for the game and other resources in [downloads](https://www.warhammer-community.com/en-gb/downloads/warhammer-40000/)
	- [Munitorum Field Manual](https://mfm.warhammer-community.com/en): Official home for up-to-date points values
	- [Faction Packs](https://www.warhammer-community.com/en-gb/downloads/warhammer-40000/): additional rules and clarifications that supplement your Codex
	- [Universal Rules Updates](https://www.warhammer-community.com/en-gb/downloads/warhammer-40000/): updates for core game rules

## Noteworthy Third Party

- [Wahapedia](https://wahapedia.ru/wh40k11ed/the-rules/core-rules/): Overwhelmed with the number of places rules exist? Wahapedia has them all in one place. An essential resource in my opinion.
- [GDM 2026](https://game-datamissions.com/11th): A great resource to read the mission cards as well as a bunch of other rules.

- Listwriting Apps:
	- [WarOrgan](https://warorgan.com/): a lesser known app that feels extremely user friendly and intuitive to use.
	- [New Recruit](https://www.newrecruit.eu/): a powerful and beloved list-building app for many game systems. A bit on the technical side, but often a go-to.
